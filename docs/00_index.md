## 0. この文書群の位置づけ

本ドキュメント群は、**実装者が誰であっても同一の成果物が得られること**を目的とした確定仕様である。

- 「〜が望ましい」「〜を検討する」といった曖昧な記述は仕様ではない。本文書群における記述は原則としてすべて **MUST（必須）** である。
- MUST 以外は `[SHOULD]` `[MAY]` を明記する。
- 本文書群と原仕様書（`パワプロ サクセス必要経験点計算アプリ 仕様書.md`, v1.0）が矛盾する場合、**本文書群を優先する**。原仕様書は背景資料として保持する。

## 3. 用語集

| 用語 | 定義 |
|---|---|
| 経験点 | サクセスで能力を上げるために消費するポイント。筋力 / 敏捷 / 技術 / 変化球 / 精神 の5種。 |
| ExpVector | 5種の経験点をまとめた値オブジェクト。本アプリの計算単位。 |
| 基礎能力 | 弾道・ミート・パワー・走力・肩力・守備力・捕球（野手）／球速・コントロール・スタミナ・守備力・捕球（投手）。 |
| 青特殊能力（青特） | 通常の特殊能力。`binary`（有無）と `rank`（G〜A）の2種がある。 |
| 金特殊能力（金特） | 上位特殊能力。取得には下位青特の所持が前提となるものがある。 |
| コツ | 特殊能力の必要経験点を減らす要素。Lv0（未所持）〜Lv5。 |
| センス○ | 必要経験点が軽減される特殊能力。本アプリでは `sense_mode` として扱う。 |
| sense_mode | `normal` / `sense_plus` の2値。データセットの切り替え軸。 |
| プラン（Plan） | 1人の作成予定選手の入力内容一式。保存・複製の単位。 |
| 実測値（measured） | ゲーム画面に表示された値を人手で記録したデータ。 |
| 推定値（estimated） | 実測値から本アプリが逆算・算出した値。 |
| 仮想基礎値 B | 金特のコツLv0相当の内部推定値。`04_calculation_spec.md` 参照。 |
| ゲームバージョン | `pawapro2024` のようなデータセット識別子。ディレクトリ名と一致する。 |

## 5. 最重要設計原則（再掲・遵守必須）

> **不明なゲーム仕様をコードで推測しない。**

| 領域 | 数値の出どころ |
|---|---|
| 基礎能力 | CSV実測値のみ。倍率計算をコードで行わない。 |
| 青特殊能力 | CSV基礎値 × CSV定義のコツ倍率 × CSV定義のセンス倍率。 |
| 金特殊能力 | 実測優先 → 不足Lvのみ推定 → 推定である旨を必ず表示。 |
| 変化球 | 実測のみ。**推定値を自動生成してはならない。** |

データ不足を `0` として計算することは、いかなる場合も禁止する。
