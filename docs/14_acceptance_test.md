## 3. AT-19 の詳細手順（新作追加テスト）

**この項目が本アプリの設計上もっとも重要**であるため、手順を確定する。

```text
1. public/data/ に新しいディレクトリ pawapro2026 を作成する
2. sample2024 の全CSVをコピーし、base_sense_plus.csv の velocity 130→131 の
   muscle を 10 から 99 に書き換える
3. public/data/games.json に以下の1エントリを追加する
     { "id": "pawapro2026", "displayName": "パワプロ2026-2027",
       "directory": "pawapro2026", "bundled": true, "note": "" }
4. src/ 配下のファイルを1つも変更せずに npm run build を実行する
5. アプリを開き、ゲーム選択に「パワプロ2026-2027」が現れることを確認する
6. これを選択し、投手 / 球速 130→131 を入力する
7. 期待: 筋力が 99 と表示される
8. ゲームを sample2024 に戻す
9. 期待: 筋力が 10 に戻る（データが混ざらない）
```

判定: 手順4で `src/` の変更が一切不要であれば **合格**。1行でも変更が必要なら **不合格**。
