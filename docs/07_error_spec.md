# 07. エラー・バリデーション仕様

---

## 1. 基本原則

1. **データ不足を 0 として計算してはならない。** 必ずエラーコードを発生させ、結果ステータスを `incomplete` にする。
2. **異常なCSVを黙って読み込んではならない。** 検証違反を検出したらロードを中止する。
3. エラーは**握りつぶさない**。`catch` した例外は必ず `issues` またはロードエラーとして画面へ到達させる。
4. エラーメッセージは**日本語**で、「何が / どこで / どうすればよいか」を含める。
5. 検証エラーは**最初の1件で打ち切らず全件収集する**（上限200件）。

---

## 2. エラーコード一覧

`src/domain/errors/errorCodes.ts` に定数として定義する。

| コード | 分類 | 発生条件 | 結果ステータスへの影響 |
|---|---|---|---|
| `BASE_DATA_MISSING` | 計算 | 基礎能力の遷移行がCSVに存在しない | `incomplete` |
| `BLUE_DATA_MISSING` | 計算 | 青特のマスタ行または遷移行が存在しない | `incomplete` |
| `GOLD_DATA_MISSING` | 計算 | 対象金特の実測行が1件も存在しない | `incomplete` |
| `BREAKING_DATA_MISSING` | 計算 | 変化球の経験点が未入力かつキャッシュ未ヒット | `incomplete` |
| `INVALID_TARGET` | 計算 | 目標値が現在値より小さい / 状態値が不正 / 値域外 | `incomplete` |
| `INVALID_CSV` | ロード | CSVの形式・型・範囲・参照整合の違反 | ロード中止 |
| `DUPLICATE_DATA` | ロード | 一意キーの重複 | ロード中止 |
| `CSV_FILE_MISSING` | ロード | 必須CSVファイルが取得できない | ロード中止 |
| `GAME_DATA_NOT_DEPLOYED` | ロード | `bundled: false` のゲームでCSVが404 | ロード中止（案内表示） |
| `STORAGE_ERROR` | 永続化 | IndexedDB の読み書き失敗 | 警告表示（計算は継続） |
| `IMPORT_REJECTED` | インポート | インポートファイルが検証に失敗し適用されなかった | 適用せず（既存データ維持） |

**コードを追加・改名してはならない。** 新しい事象が必要になった場合は本仕様を改訂すること。

## 3. メッセージ文言（確定）

`{}` はプレースホルダ。実装時にこの文言をそのまま使用する。

### 3.1 計算エラー

| コード | 文言 |
|---|---|
| `BASE_DATA_MISSING` | `{能力名} {from}→{to} の経験点データがありません。{ファイル名} を確認してください。` |
| `BLUE_DATA_MISSING` | `青特「{能力名}」の {from}→{to} の経験点データがありません。blue_abilities.csv を確認してください。` |
| `BLUE_DATA_MISSING`（マスタ自体なし） | `青特「{能力ID}」が blue_abilities.csv に登録されていません。` |
| `GOLD_DATA_MISSING` | `金特「{能力名}」の実測データが1件もありません。gold_abilities.csv に実測値を追加してください。` |
| `BREAKING_DATA_MISSING`（一括未入力） | `変化球経験点が未入力です。` |
| `BREAKING_DATA_MISSING`（ステップ未解決） | `変化球ステップ {seq}（{球種} {from}→{to}）の経験点が未登録です。入力するか共通キャッシュに登録してください。` |
| `INVALID_TARGET`（目標<初期） | `{能力名} の目標値は初期値以上にしてください。` |
| `INVALID_TARGET`（値域外） | `{能力名} の値は {min}〜{max} の範囲で入力してください。` |
| `INVALID_TARGET`（状態不正） | `「{能力名}」の状態「{値}」は不正です。` |

### 3.2 ロードエラー

| コード | 文言 |
|---|---|
| `CSV_FILE_MISSING` | `{ファイル名} が見つかりません。public/data/{ディレクトリ}/ を確認してください。` |
| `GAME_DATA_NOT_DEPLOYED` | `このゲームのデータが配置されていません。CSVをインポートしてください。` |
| `INVALID_CSV`（カラム欠落） | `{ファイル名}: 必須カラム「{カラム名}」がありません。` |
| `INVALID_CSV`（型） | `{ファイル名} {行}行目: 列 {カラム名} の値「{値}」は 0 以上の整数ではありません。` |
| `INVALID_CSV`（空欄） | `{ファイル名} {行}行目: 列 {カラム名} が空欄です。経験点は 0 と空欄を区別します。` |
| `INVALID_CSV`（列挙値） | `{ファイル名} {行}行目: 列 {カラム名} の値「{値}」は {許容値一覧} のいずれかである必要があります。` |
| `INVALID_CSV`（遷移） | `{ファイル名} {行}行目: to_value は from_value + 1 である必要があります（from={from}, to={to}）。` |
| `INVALID_CSV`（参照） | `{ファイル名} {行}行目: {カラム名}「{値}」が {参照先ファイル} に存在しません。` |
| `DUPLICATE_DATA` | `{ファイル名} {行}行目: キー（{キー内容}）が {既出行}行目と重複しています。` |

### 3.3 永続化・インポート

| コード | 文言 |
|---|---|
| `STORAGE_ERROR`（保存失敗） | `保存に失敗しました。ブラウザの保存容量が不足している可能性があります。入力内容は画面上に保持されています。` |
| `STORAGE_ERROR`（読込失敗） | `保存データの読み込みに失敗しました。` |
| `IMPORT_REJECTED` | `インポートは適用されませんでした。以下のエラーを修正してください（{件数}件）。` |

## 4. 例外設計

```ts
// src/domain/errors/appError.ts
export class AppError extends Error {
  constructor(
    readonly code: string,
    message: string,
    readonly detail?: Record<string, unknown>
  ) { super(message); this.name = "AppError"; }
}
```

| 層 | 例外の扱い |
|---|---|
| `domain/calculator/*` | **例外を投げない。** `issues` 配列へ収集して返す（計算は最後まで進める）。 |
| `domain/estimator/*` | 同上。推定不能は呼び出し元が `GOLD_DATA_MISSING` として扱う。 |
| `data/csv/validators` | 例外を投げない。`ValidationIssue[]` を返す。 |
| `data/repositories/gameDataLoader` | 致命的な取得失敗のみ `AppError` を投げる。呼び出し元のストアが捕捉して `status = "error"` にする。 |
| `data/persistence/*` | `AppError(STORAGE_ERROR)` を投げる。ストアが捕捉して警告バーを表示し、処理は継続する。 |
| `ui/*` | React の Error Boundary を最上位に置き、未捕捉例外時に「予期しないエラーが発生しました。再読み込みしてください。」を表示する。 |

**`console.log` によるエラー通知は禁止**（利用者に届かないため）。デバッグ出力は本番ビルドから除去すること。

## 5. 入力バリデーション一覧（UI層）

| 入力 | ルール | 違反時 |
|---|---|---|
| 選手名 | 1〜50文字。前後空白はトリム。 | 赤枠＋「選手名を1〜50文字で入力してください。」 |
| 基礎能力の初期値/目標値 | 整数、`[min_value, max_value]` | 範囲外は範囲内へクランプし、赤枠で通知 |
| コツLv | 0〜5の整数 | セレクトのため発生しない |
| 変化球 変化量 | 1〜7の整数 | セレクトのため発生しない |
| 変化球 一括経験点 | 0以上の整数、5項目すべて必須 | 未入力欄を赤枠＋「0以上の整数を入力してください。」 |
| 変化球 前総変化 | 0〜99の整数 | 赤枠＋範囲メッセージ |
| 変化球 前球種数 | 0〜10の整数 | 赤枠＋範囲メッセージ |
| CSVファイル | 拡張子 `.csv`、20MB以下 | 「CSVファイル（20MB以下）を選択してください。」 |
| プランJSON | `format` 一致、`formatVersion` 対応 | 「このファイルは本アプリのプランJSONではありません。」 |

## 6. ログ

| 項目 | 規定 |
|---|---|
| 外部送信 | **禁止**（06章 §7） |
| 開発ビルド | `import.meta.env.DEV` のときのみ `console.debug` を許可する |
| 本番ビルド | `console.*` の呼び出しをビルド時に除去する（`esbuild` の `drop` オプション等） |
| 利用者向け診断 | 「このアプリについて」画面に、ロード済みデータの件数・インポート状態・スキーマ版を表示する `[SHOULD]` |
